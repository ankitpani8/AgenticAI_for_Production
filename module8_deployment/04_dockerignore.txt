# Module 8 — .dockerignore
#
# Rename this file to `.dockerignore` in your build context root:
#     cp 04_dockerignore.txt .dockerignore
#
# It's kept here as .txt so it stays VISIBLE in the repo listing (dotfiles hide)
# and so a reader sees it exists at all -- a forgotten .dockerignore is one of
# the most common ways secrets and multi-hundred-MB junk end up baked into an
# image. Everything matched here is EXCLUDED from the build context, so it can
# never reach a layer.
